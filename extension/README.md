# HackMirror 批量取关助手（浏览器扩展）

在 `x.com` 页面里，用你自己的登录态批量取关 HackMirror 选中的账号。

- 不保存、不上传任何凭据
- 取关请求在 `x.com` 页面内以你的会话执行
- 默认每个账号间隔 2–3.5 秒，按 `Esc` 或扩展里的「停止」可中断

## 安装

1. 打开 Chrome / Edge 的扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选择本仓库的 `extension/` 目录
5. 建议把扩展固定到工具栏，方便打开

## 使用

1. 在 HackMirror 结果列表打开「多选」，勾选要取关的账号
2. 点「复制取关清单」（复制的是 JSON，包含账号 ID）
3. 点扩展图标，点「从剪贴板粘贴」或手动粘贴
4. 点「开始取关」
5. 扩展会打开或复用 `x.com` 标签页并开始执行；进度看该页面的控制台（F12）
6. 完成后会弹窗显示成功 / 失败数量

## 注意

- 自动化取关可能触发 X 的风控或限流，**建议每次不超过 50 个**，分多次执行。
- 需要已经登录 `x.com`；未登录会提示。
- 取关接口和 Bearer token 属于 X 内部接口，随时可能改版；如果全部失败（401/403），说明接口已变化，需要更新 `popup.js` 里的请求。
- 这个扩展只做取关，不做关注、发帖等其他操作。

## 文件

- `manifest.json`：MV3 配置
- `popup.html` / `popup.js`：输入清单、注入 x.com 执行
